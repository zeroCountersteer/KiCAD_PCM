# TI package/model naming

Live WEBENCH rows pair BXL package variants with package-level STEP names. In the acquired `SN7400` row, the models are `D0014A.stp`, `N0014A.stp`, and `NS0014A.stp`; the current canonical BXL selected from repeated observations is `N14`. The exporter code is normalized by removing trailing `A` and leading zeroes: `N0014A → N14`.

Association requires the same MPN and normalized package code. `D0014A` is not attached to `N14`, and absent D14 variants are not invented.
